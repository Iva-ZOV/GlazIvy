# Глаз Ивы

Простое десктоп-приложение для Windows: доска, на которую камеры
видеонаблюдения клеятся как стикеры. Каждую камеру можно двигать, растягивать
и настраивать отдельно. Работает **локально**, без облака — видео с ваших
IP-камер идёт напрямую по RTSP.

> Никаких аккаунтов и подписок. Данные камер хранятся только на вашем
> компьютере и никуда не отправляются.

## Возможности
- Несколько камер одновременно на одной доске.
- Свободное размещение: перетаскивание, изменение размера, наложение.
- На каждой плитке — переключатели **SD/HD** и **TCP/UDP**, индикатор связи,
  настройки (шестерёнка) и удаление.
- Автоматическое переподключение при обрыве связи, удержание последнего кадра.
- Тёмный интерфейс, безрамочное окно, полноэкранный режим (F11).
- Раскладка и список камер сохраняются между запусками.

## Скачать готовую программу
Смотрите раздел **[Releases](../../releases)** — там лежит готовый архив
`GlazIvy-portable-...zip`. Скачайте, распакуйте **всю папку** и запустите
`GlazIvy.exe`. Python устанавливать не нужно.

При первом запуске Windows SmartScreen может показать «Неизвестный издатель»
(приложение не подписано платным сертификатом). Нажмите **«Подробнее» →
«Выполнить в любом случае»**.

## Как добавить камеру
1. Нажмите **«＋ Добавить камеру»**.
2. На появившейся плитке нажмите шестерёнку (⚙).
3. Введите данные вашей камеры: имя, IP-адрес, порт (обычно 554), логин,
   пароль, транспорт (TCP/UDP), качество (SD/HD). Сохраните.
4. Двигайте и растягивайте плитку как удобно.

Формат RTSP-потока и учётные данные зависят от модели камеры — смотрите
инструкцию к вашей камере или её приложение.

## Запуск из исходников
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## Сборка .exe (Windows)
```powershell
.\build.ps1 -Python ".\.venv\Scripts\python.exe"
```
Результат — в `dist\GlazIvy\` и переносимый архив в `release\`.

## Технологии
Python + PySide6 (Qt6) для интерфейса, OpenCV (FFmpeg) для приёма RTSP.
