# Шрифты и текстура интерфейса

Интерфейс использует **Inter** для основного текста и **Unbounded** для
фирменных и диалоговых заголовков. В каталоге лежат статические веса Inter
400/500/600/700 и Unbounded 500/600/700; приложение регистрирует все `.ttf`
через Qt, а PyInstaller включает каталог `assets` целиком.

Оба семейства распространяются по лицензии **SIL Open Font License 1.1**.
Исходники взяты из официальных репозиториев Google Fonts, статические веса
нарезаны из вариативных TTF с помощью fontTools.

Если вложенные шрифты недоступны, основной текст переключается на системный
`Segoe UI Variable Text`/`Segoe UI`, а заголовки используют тот же fallback.

Текстура `assets/textures/grain.png` сгенерирована процедурно для этого
интерфейса; она накладывается с низкой непрозрачностью только на статические
поверхности.
