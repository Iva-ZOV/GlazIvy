# Шрифт интерфейса

Приложение в первую очередь запрашивает семейство **Inter**. Если рядом с этим
файлом лежат официальные `Inter-Regular.ttf`, `Inter-Medium.ttf` и
`Inter-SemiBold.ttf`, они автоматически регистрируются через Qt и попадают в
сборку PyInstaller.

Без вложенных TTF используется системный `Segoe UI Variable Text` (Windows 11)
или `Segoe UI` (Windows 10). Это штатный офлайн-fallback с близкими метриками;
он не требует распространения сторонних бинарных файлов.
